    Why a geometry operation failed

    • invalid-input: the input is not a polygon the operation can take (a degenerate segment, a malformed ring)
    • unclosed-ring: the output ring could not be closed, typically because edges nearly coincide within floating-point precision (still failing after the retry on the grid)
    • too-complex: the operation gave up on an input too large or tangled for it
    • internal: any other failure inside the boolean operation engine
