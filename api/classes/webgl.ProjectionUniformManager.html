    setUniforms

    • setUniforms(
          projectionData: ProjectionData,
          zoom: number,
          offsetUniforms: OffsetUniforms | null,
          originShift?: [number, number],
      ): void

      Sets the projection uniforms

      A uniform whose value is the same as last time is not rewritten. Retained mode passes through here for every chunk, but the only thing that changes between chunks is u_origin_shift; the matrix and the camera-related values are invariant within a frame (see frame.ts).

      Parameters

      • projectionData: ProjectionData

        MapLibre's ProjectionData

      • zoom: number

        The current zoom level

      • offsetUniforms: OffsetUniforms | null

        The uniforms for offset mode (null is allowed)

      • originShift: [number, number] = ...

        The gap between the reference coordinates of the vertex offsets and the linearization center (the default is [0,0])

      Returns void
