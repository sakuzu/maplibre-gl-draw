    Module maplibre-gl-draw

    Draw and edit points, lines and areas on a MapLibre map, and show large data beside them.

    Import from here for everything an application does with a drawing: create the instance, read and change its features, layers and groups, listen to what changes, save and load the document, and add plugins, modes and feature types. Three subpaths cover the rest: geometry that needs no map (/geometry), large tables read in a Worker (/table) and custom shaders (/webgl).

    import { createDraw } from '@sakuzu/maplibre-gl-draw';

    const draw = createDraw(map);
    draw.setMode('draw_polygon');
    draw.on('feature.created', ({ feature }) => {
      console.log(feature.id, feature.geometry);
    });

    Read next: getting started, then the guides for drawing and saving and loading. The symbols used most are createDraw, Draw, Feature and DrawEvents.
