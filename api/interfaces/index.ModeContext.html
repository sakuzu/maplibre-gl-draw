    Interface ModeContext

    The services of the draw instance a mode works with, passed to ModeHandler.onStart.

    Note: the redraw is triggered automatically by RenderCoordinator subscribing to Store changes, so a mode does not need to call requestRepaint() explicitly.

    getCurrentLayerId

    getCurrentLayerId: () => string

    Gets the ID of the writable layer, the layer that new features are written into

    The active layer when it exists, is not locked, is visible and is not locally hidden, otherwise the first such layer, otherwise an empty string. A mode reads it when it commits a feature; when it is an empty string the mode must not create the feature: it discards the drawing (clears the tentative state) and returns to select.
