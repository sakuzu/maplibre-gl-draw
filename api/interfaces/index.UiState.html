    Interface UiState

    The local state of this instance: never part of the document, owned by core

    Core keeps it for every draw instance, whatever DocumentStore holds the document. The host reads it through StoreView and changes it through the methods of the draw instance (setMode, setSelection, setReadOnly and so on).
