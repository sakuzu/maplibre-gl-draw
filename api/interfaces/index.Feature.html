    Interface Feature

    A feature of the document: its geometry, the layer and group it belongs to, its attributes and its style

    The draw instance returns features from getFeature, getAllFeatures and the events, and creates them from a FeatureInput. What the instance returns is read-only: change a feature with updateFeature, which stores a new object.

    The stacking order of the features is not a property of the feature: it is the position of its ID in Layer.order, or in Group.featureIds when it belongs to a group.

Core also reads and writes a few keys of its own here: name and description, createdZoom, rotation and scale (see getCreatedZoom, getRotation and getScale), radiusMeters and radiusHandleAngle of a Circle, and the keys of ImageProperties of an Image.
