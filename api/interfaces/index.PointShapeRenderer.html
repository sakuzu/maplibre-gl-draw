    Interface PointShapeRenderer

    The point renderer core uses for point markers (circles, squares, triangles and stars; the shape 'icon' is drawn as a circle), shared with custom feature renderers.

    Draws a billboard of a size in CSS px at a [lng, lat] position in degrees, converting to clip space on the GPU. Call ensureShader, setOffsetUniforms and setProjectionData before drawing.
