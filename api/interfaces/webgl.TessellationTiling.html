    Interface TessellationTiling

    The subdivision step of each terrain tile, indexed by a grid of cells.

    The set of tiles is indexed by cells the size of the finest tile. A coarse tile spans several cells, but a cell boundary always lies on one of that tile's mesh lines (the side length of the finest tile is an integer multiple of the mesh interval), so cutting along the cells does not create a seam.
