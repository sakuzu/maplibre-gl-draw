    transact

    • transact<T>(fn: () => T, options?: TransactOptions): T

      Runs fn as one transaction: its writes arrive as one document.changed.

      In nested calls the source of the outermost call wins. With ignoreLocks, the writes of fn through the resources of this instance ignore the locks of the features, groups and layers, as a change applied again from a record needs; read-only still refuses them, and what the user does with the pointer and the keys still respects the locks. A nested call inside such a call ignores them as well.
