    Interface SnappingOperations

    The snapping of a draw instance, reached as draw.snapping: switching it at runtime, reading its settings and adding candidates.

    Snapping replaces the coordinate of a click, a move or a drag with the nearest candidate within the tolerance, before any mode sees it, so it works the same way in every mode and for vertex dragging. The initial settings come from Options.snap. Holding the modifier of disableKey (Alt by default) releases it while held. Every change of the result is announced by the draw.snap.change event.

    Example

    draw.snapping.setEnabled(false);
    draw.snapping.setKindEnabled('guide', false); // turn off guides only
    const unregister = draw.snapping.register(myProvider);
    unregister();

    resolve

    • resolve(
          lngLat: SnapLngLat,
          point?: ScreenPoint,
          ctx?: Partial<SnapContext>,
      ): SnapResult

      Resolves snapping for a coordinate.

      There is no need to call it for normal input, because the InputRouter passes it through automatically. It is the entry point for when a coordinate produced outside the library, such as numeric input or synthetic input, should be passed through snapping.

      Parameters

      • lngLat: SnapLngLat

        the input coordinate

      • Optionalpoint: ScreenPoint

        the screen coordinate (when omitted, it is computed with map.project)

      • Optionalctx: Partial<SnapContext>

        overrides for the context (when omitted, zoom is the current zoom and modifiers are all false)

      Returns SnapResult

      the snapped coordinate and what it snapped to; the input coordinate with no target when nothing is within the tolerance

      Example

      const { lngLat, target } = draw.snapping.resolve({ lng: 139.7, lat: 35.68 });
      if (target) console.log('snapped to a', target.kind);

    setGuideStep

    • setGuideStep(degrees: number): void

      Sets the step angle of the built-in north-based guides.

      The initial value is options.snap.guideStepDegrees (default 45, which gives 8 guides). The change takes effect from the next snapping query. A value of 0 or less, or a non-finite value, gives the default 45. The current value is in getOptions().guideStepDegrees. Guides added with createGuideSnapProvider keep their own step.

      Parameters

      • degrees: number

        the step angle in degrees, counted from true north

      Returns void

      Example

      draw.snapping.setGuideStep(15); // 24 guides, every 15 degrees
