    Interface GroupsCollection

    The groups of the document, with the standard methods of a collection and the verbs that move them.

    A wrong argument (an ID that does not exist, an input of the wrong shape) throws a DrawError and changes nothing. A refusal because of the state (read-only, a lock) returns null or false and changes nothing. A method whose name ends in Many runs in one transaction: all of it happens or none of it does.
