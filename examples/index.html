Examples ​

Each example is a page of its own: the example runs live, and its code is below it. Every example lays the standard UI over the map, except the last one, which builds a UI of its own on the public API. The playground puts every feature on one page.

  • PlaygroundEvery feature of the library on one page: the standard UI with all its parts, a plugin and a custom feature type with their tools and sections, terrain, the globe, a dataset, read-only and the interaction lock, saving in the browser, and 200,000 features.
  • Get startedThe smallest page: a map with the standard UI over it, where the user draws, selects and changes features.
  • Style featuresThe look of each feature, side by side: fill and outline colors, solid, dashed and dotted lines of several widths, and the four shapes of a point in four sizes.
  • Feature propertiesThe attributes of features, loaded from GeoJSON and changed in the panel and from code.
  • Zoom and scaleWidths in pixels at the reference zoom of each feature grow and shrink with the map like paint on the ground; without a reference zoom they stay the same on the screen.
  • Editing shapesThe handles of a selected feature: the frame that resizes and rotates it, its vertices and midpoints, an area with a hole, an area of two parts, and two parcels whose shared vertices move together.
  • Layers and groupsLayers and groups made from code, with their order, visibility, locks and opacity in the layer panel.
  • Style rules and legendThe four kinds of style rule color 400 buildings of central Tokyo from an attribute, the legend shows what each color means, and a height edited in the panel changes the color at once.
  • Snapping and tracingSnapping to vertices, edges and guide lines, and tracing the boundary of a feature that is already there.
  • Geometry operationsUnion, intersection, difference, split and buffer from the panel, with the length and the area of the selection.
  • ImagesImages on the map: a file picked with the Image tool, and an image placed from code.
  • Save and loadGeoJSON and the format of the library, saved in the browser, downloaded as files and opened from the disk, files dropped on the map, and the features a load leaves out.
  • TerrainDrawing and editing on the 3D terrain of the map.
  • GlobeRoutes between the continents along great circles, a box between meridians and parallels, a circle of 2,500 km, a picture and six cities on the globe, and an area across the antimeridian.
  • 200,000 featuresA made-up city of 208,073 features (buildings, parks, streets and places) loaded in one step and seen from a tilted camera, every one of them editable.
  • DatasetsOver a million rows beside an editable drawing: 1,000,000 points fetched for the view and thinned, 250,000 cells given at once, and the buildings and the places of central Tokyo from Overture Maps, with the drawing snapping to the buildings.
  • Columnar data in a WorkerA GeoParquet file of the buildings of central Tokyo read in a Worker and handed to a dataset as columns, and a million points made there from a switch: no GeoJSON, no object per row, and no copy on the way to the page.
  • Read-only viewerA page that shows a drawing to look at, not to edit, and four switches that turn read-only, the interaction lock, a locked layer and local hiding on and off apart, to show what each of them stops.
  • PluginsA plugin adds a mode of its own to the drawing, and the page adds a tool for that mode to the toolbar and a section for its features to the panel on the right. A switch removes the plugin with all it brought, and adds it again.
  • Custom feature typesA feature type the library does not have: a route, a line with style keys of its own, which its definition draws, hits and takes into a selection box, a section of the panel on the right for its keys, and a switch that unregisters the type and registers it again.
  • Build your own UINo standard UI: a toolbar and a panel of the selected feature built with the public API of the library alone, in plain TypeScript and a few rules of CSS. Everything the standard UI does is reachable this way.

The code of the examples is in examples/ of the repository, with how to run them on your machine.
