Examples ​

例は 1 つずつ自分のページを持ちます。ページの上で例が動き、その下にコードがあります。最後の 1 つを除くすべての例は、標準の UI を地図に重ねます。最後の例は、公開 API だけで自分の UI を作ります。すべての機能を 1 つのページに載せたものが playground です。

  • Playgroundライブラリーのすべての機能を 1 つのページに載せています。すべての部品を出した標準の UI、道具と節を足したプラグインと独自の地物の型、地形、地球儀、データセット、読み取り専用と操作の錠、ブラウザーへの保存、20 万の地物です。
  • Get startedいちばん小さなページです。地図に標準の UI を重ね、利用者が地物を描き、選び、直せるようにします。
  • Style features地物ごとの見た目を並べて比べます。塗りと輪郭の色、太さの違う実線と破線と点線、点の 4 つの形と 4 つの大きさです。
  • Feature properties地物の属性です。GeoJSON から読み込み、パネルとコードで直します。
  • Zoom and scale地物ごとの基準のズームでのピクセルの太さは、地面に塗った線のように地図とともに太くも細くもなります。基準のズームを持たない地物は、画面の上で同じ太さのままです。
  • Editing shapes選んだ地物のハンドルです。大きさを変えて回す枠、頂点と辺の中点、穴のある面、2 つの部分からなる面、共有する頂点がいっしょに動く 2 つの区画です。
  • Layers and groupsコードで作ったレイヤーとグループです。重なりの順、表示、ロック、不透明度をレイヤーのパネルに出します。
  • Style rules and legend4 種類のスタイル規則で東京都心の建物 400 件を属性から塗り分け、凡例に色の意味を出します。パネルで高さを直すと、色もすぐに変わります。
  • Snapping and tracing頂点、辺、ガイド線への吸着と、すでにある地物の境界のなぞりです。
  • Geometry operationsパネルから結合、交差、差、分割、バッファーを使い、選んだ地物の長さと面積を測ります。
  • Images地図に置く画像です。画像の道具で選んだファイルと、コードで置く画像です。
  • Save and loadGeoJSON とライブラリーの形式を扱います。ブラウザーへの保存、ファイルのダウンロード、ディスクのファイルを開くこと、地図に落としたファイル、読み込みで外された地物です。
  • Terrain地図の 3D の地形の上で描き、直します。
  • Globe大陸の間を大円で結ぶ経路、経線と緯線に挟まれた四角形、半径 2,500 km の円、画像、6 つの都市を地球儀の上に描き、日付変更線をまたぐ面も置きます。
  • 200,000 features建物、公園、街路、場所からなる 208,073 の地物の架空の町を 1 度で読み込み、傾けたカメラで見ます。どの地物も編集できます。
  • Datasets100 万を超える行を、編集できる描いたものと並べて表示します。見えている範囲ごとに取り寄せて間引く 100 万の点、一度に渡す 25 万のセル、Overture Maps の東京都心の建物と場所を置き、描く線は建物に吸着します。
  • Columnar data in a Worker東京都心の建物の GeoParquet ファイルを Worker で読んで列のままデータセットに渡し、スイッチで 100 万の点もそこで作ります。GeoJSON を経ず、行ごとのオブジェクトも作らず、コピーもしません。
  • Read-only viewer描画を見るためのページです。4 つのスイッチで、読み取り専用、操作の錠、レイヤーのロック、ローカルの非表示を別々に切り替え、それぞれが何を止めるかを見せます。
  • Pluginsプラグインで描画に独自のモードを足し、ページはそのモードの道具を道具のバーに、その地物のための節を右のパネルに足します。スイッチで、プラグインを持ち込んだものごと取り除き、また足します。
  • Custom feature typesライブラリーにない地物の型です。ルートは独自のスタイルのキーを持つ線で、その定義が描き方、当たり判定、範囲選択を決めます。右のパネルには、そのキーのための節を足します。スイッチで型の登録を外し、また登録します。
  • Build your own UI標準の UI を使いません。道具のバーと、選んだ地物のパネルを、ライブラリーの公開 API だけで作ります。素の TypeScript と数行の CSS で書きます。標準の UI ができることは、すべてこの方法で作れます。

例のコードはリポジトリの examples/ にあり、手元で動かす方法もそこに書いています (英語)。
