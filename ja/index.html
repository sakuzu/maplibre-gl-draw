maplibre-gl-drawMapLibre の地図で図形を描き、編集する

独自の WebGL2 の描画で、20 万の地物を編集できるまま描きます。平らな地図でも、3D の地形の上でも、地球儀でも同じように描けます。

はじめかた
Playground を試す
例

描いて直す

点、線、面、円、フリーハンドの線を描けます。選んで動かし、大きさを変え、回し、頂点を直せます。吸着となぞりも使えます。

20 万の地物を編集できる

描画全体を GPU で描くので、大きな描画も編集できるまま扱えます。

地形と地球儀

傾けた地図でも、3D の地形の上でも、地球儀でも同じように描けます。日付変更線もまたげます。

データセット

数万の区画や 100 万の点を、描いたものの横に速く表示できます。GeoJSON の地物からも、GeoParquet や Arrow の列からも直接渡せます。

どこでも使える幾何演算

結合、差、交差、分割、バッファー、長さ、面積は、Node や Worker でも動く普通の関数です。

拡張できる

プラグイン、モード、地物の型、重ね描き、提供者を、どれも同じ方法で足せます。組み込みの描画モードも同じ窓口で書かれています。

インストール ​

sh
npm install @sakuzu/maplibre-gl-draw

maplibre-gl は peer dependency です。アプリにすでに入っている maplibre-gl を使います。まだ入っていなければ、npm 7 以降は一緒にインストールされます。

続けて はじめかた に沿って、最初の面を描いてください。

見てみる ​

東京の中心の上の playground の描画、同じ描画を傾けて回した地図、地球儀、3D の地形、208,073 の編集できる地物の街です。
