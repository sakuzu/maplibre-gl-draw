# 200,000 features

208,073 の地物からなる町を、1 度で描いたものに読み込みます。
どの地物も編集できます。

```example
200000-features
```

町は架空のもので、東京の都心の西に、曲がった格子の街路で作って
います。傾けたカメラで見ており、手前では地物を 1 つずつ見分けられ、
奥では遠くまで続きます。面が 174,435 (建物と緑の公園)、線が
24,328 (街路と赤の大通り)、点が 9,310 (カフェ、診療所、パン屋)
あります。広い画面では、手前の公園は、選ばれて頂点のハンドルが出た状態で
開きます。

地物は、手で描いた地物と同じです。建物をクリックして選ぶと、右の
パネルの属性に用途が出ます。ドラッグで動かしたり、頂点を動かしたり、
Delete キーで消したりできます。拡大すると手前の建物に寄り、縮小すると
町の全体が見えます。地物の数と読み込みにかかった時間は、ブラウザーの
コンソールに出ます。

## コード

標準の UI のレイヤーのパネルは、1 つのレイヤーの地物を 1,000 まで
並べます (3)。町のどのレイヤーにもそれより多くの地物があるので、
パネルは地物ごとの行の代わりに、レイヤーの下の行に地物の数を出します。
建物は地図の上で選びます。町は、種を決めた乱数でコード (`data.ts`)
から作るので、いつ開いても同じです (4)。`draw.document.load` は
208,073 の地物を 1 つのトランザクションで書き込みます (5)。変更も
イベントも描き直しも 1 回です。`draw.features.createMany` も 1 つの
トランザクションです。公園は、読み込みが終わってからコードで選びます。
選ぶのは広い画面 (48rem 以上) のときだけです。
