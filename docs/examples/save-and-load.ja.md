# Save and load

描いたものを書き出し、読み戻します。GeoJSON とライブラリーの形式、
地図に落としたファイル、読み込みで外された地物を扱います。

```example
save-and-load
```

このページは 5 つの地物を持つ GeoJSON のファイルで開きます。4 つは
描いたものに足されます。5 つ目は位置が 1 つしかない線なので外され、
その理由がブラウザーのコンソールに出ます。このページは自分のボタンを
持たず、切り替えはキーで行います。キーの一覧はページを開いたときに
コンソールに出ます。パネルの欄に入力している間は、キーは働きません。

| キー | すること |
| --- | --- |
| `S` | 文書の全体をライブラリーの形式でこのブラウザーに保存する |
| `O` | 保存した文書を描いたものの代わりに読み込む |
| `D` | 文書をライブラリーの形式でダウンロードする |
| `G` | 地物を GeoJSON でダウンロードする |
| `B` | ディスクのファイルを開く |

描いたものを変えてから `S` を押してください。`O` を押すと読み戻せます。
ページを読み直しても、保存した文書で開きます。`D` と `G` は同じ描いた
ものをファイルに保存します。ファイルの名前は描いたもののタイトルから
付けます。`B` を押すとブラウザーのファイルの選択が開きます。そこで選んだ
GeoJSON のファイル、保存した文書、画像は、地図に落としたときと同じように
読み込まれます。地図にファイルを落とすと、その場所に読み込まれます。
画像は落とした場所に置かれます。

## コード

`draw.document.load` は中身から形式を判断して読み込み (2)、形式、
読んだ地物、外した地物を `LoadResult` で返します (1)。
`draw.document.toJSON` はレイヤー、グループ、その順序を含む文書の
全体を書き出し、`draw.document.toGeoJSON` は地物だけを書き出します
(3)。ライブラリーの形式の文書は、読み込むと描いたものを置き換えます
(4)。ダウンロードは、文字列から作った `Blob` と、ファイルの名前を付けた
リンクで行います (5)。ディスクのファイルは、`B` を押したときに作る
入力の欄から受け取ります (6)。キー (7) とファイルの落とし込み (8) は
ページが受け持ちます。ライブラリーはこれらをアプリケーションに任せて
います。
