# Globe

地球儀の上で描きます。2 つの場所を結ぶ最短の道である大円と、
日付変更線をまたぐ面を置いています。

```example
globe
```

赤い線は、ロンドンから東京までシベリアの北を通る大円です。破線は、
同じ 2 つの場所を 2 つの頂点で結んだ線です。頂点の間の辺は、地図の
レイヤーと同じく平らな地図の上での道筋をたどります。そのため、大円は
その上に多くの頂点を並べて描きます。黄色の面は、フィジーの東で
日付変更線をまたいでいます。ドラッグで地球儀を回し、下の道具で
描けます。右下の地球儀のボタンで、平らな地図と行き来します。

## コード

投影は地図のものです。スタイルを読み込んだあとに `map.setProjection`
で設定し (1)、ライブラリーはそれに従います。大円はページが自分で
計算し、その上の点の列にします (2)。並べて 2 つの頂点の線を置きます
(3)。日付変更線をまたぐ面は、経度が -180 に飛ばずに 180 を越えて
続きます (4)。線をまたいで描いた形も、このように保たれます。地球儀の
ボタンは、標準の UI の地図の操作ボタンの 1 つです (5)。
