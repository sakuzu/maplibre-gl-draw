# Globe

地球儀の上で描きます。大陸の間を大円で結ぶ経路、2 本の経線と 2 本の
緯線に挟まれた四角形、半径 2,500 km の円、画像、6 つの都市がどれも
球面の上にあり、日付変更線をまたぐ面も置いています。

```example
globe
```

桃色と紫の線は、都市の間の最短の道である大円に沿った経路です。東京から
シベリアの北を通ってロンドンへ、東京からパースへ、ドバイからパースへ、
シンガポールからドバイとロンドンを経てニューヨークへ向かいます。
ニューヨークへの経路は地球儀の裏へ回ります。橙色の四角形は東経 50 度
から 100 度、北緯 5 度から 38 度の範囲で、4 つの角で与えています。
2 つの頂点の間の辺は、地図のレイヤーと同じく平らな地図の上での道筋を
たどるので、四角形の辺は経線と緯線に沿います。そのため、大円はその上に
多くの頂点を並べて描きます。青い破線はロンドンと東京を 2 つの頂点だけで
結んだ線で、その 1 本の辺は大円でなく平らな地図の上の直線をたどります。
青い円は東京から 2,500 km の範囲で、嵐の画像は太平洋の上にあります。
黄色の面は、フィジーの東で日付変更線をまたいでいます。ドラッグで
地球儀を回し、下の道具で描けます。右下の地球儀のボタンで平らな地図と
行き来すると、経路の曲がり方がわかります。

## コード

投影は地図のものです。スタイルを読み込んだあとに `map.setProjection`
で設定し (1)、ライブラリーはそれに従います。ページは面、経路、都市の
3 つのレイヤーを作り、data.ts の地物を 1 度の呼び出しでそこに作ります
(2)。経路は data.ts の中で大円の上の点の列として計算し、点の間隔は
弧で 2 度以下です。日付変更線をまたぐ面は、経度が -180 に飛ばずに 180 を
越えて続きます。線をまたいで描いた形も、このように保たれます。地球儀の
ボタンは、標準の UI の地図の操作ボタンの 1 つです (3)。嵐は canvas で
作った画像で、`document.load` でズーム 3 のときのピクセルの大きさで
置きます (4)。
