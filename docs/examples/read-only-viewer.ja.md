# Read-only viewer

描画を見るためのページです。利用者は地物を選んで属性を読めます。4 つの
キーで、編集を止める 4 つの方法を別々に切り替え、それぞれが何を止めるかを
見せます。

```example
read-only-viewer
```

街区か停留所をクリックしてください。右のパネルに名前、計測値、属性が
文字で出ます。描画が読み取り専用の間は、そこで何も変えられず、削除と
ロックのボタンは押せません。隠すボタンは残ります。隠すのはこのページの
中だけのことで、何も書き込まないからです。左の凡例のタブには、街区の
用途ごとの色が出ます。

このページは読み取り専用で開き、ほかの 3 つは切れています。切り替えは
キーで行います。キーの一覧はページを開いたときにブラウザーのコンソールに
出ます。パネルの欄に入力している間は、キーは働きません。どのキーも、
切り替えた後の状態をコンソールに出します。

| キー | 切り替え | 止めるもの |
| --- | --- | --- |
| `R` | 読み取り専用 | 利用者とコードからのすべての書き込み |
| `K` | 操作の錠 | 利用者の操作だけ |
| `B` | Blocks のレイヤーのロック | そのレイヤーの地物へのすべての変更 |
| `H` | このページで街区を隠す | 何も止めません。ここで描かないだけで、何も保存しません |

読み取り専用の間も、道具のバーの道具は始まりますが、描いたものは残り
ません。レイヤーのロックも書き込みなので、`B` も断られます。`R` を
押して書き込めるようにしてから `K` を押してください。道具は始まらなく
なり、何も動かせなくなります。それでもクリックで選べますし、コードは
書き込めます。もう一度 `K` を押してから `B` を押すと、街区は選べても
動かせず、変えられなくなります。停留所は動かせます。`H` は、読み取り
専用の間も、このページで街区を隠します。文書の中のレイヤーは見える
ままなので、次に開いたときもほかの人も、街区を見られます。

## コード

先に、描画を 2 つのレイヤーに読み込みます (3)。まだ書き込めるうちに
読み込むためです。次に `setReadOnly(true)` で、利用者からもコードからも
書き込みをすべて断ります (4)。標準の UI は、オプションで見るためのページに
合わせます (2)。レイヤーのパネルでは追加も並べ替えもさせず、
インスペクターは属性のタブだけにして演算を出しません。描画が読み取り
専用の間は、インスペクターが出す欄はすべて変えられなくなります。4 つの
切り替え (5) は、`setReadOnly`、`setInteractionLocked`、`locked` を渡す
`layers.update`、`draw.hidden` です。`layers.update` は断られると `null`
を返します。`draw.hidden` はレイヤー、グループ、地物の ID を受け取ります。
キー (6) はページが受け持ちます。
