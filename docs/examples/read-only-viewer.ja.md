# Read-only viewer

描画を見るためのページです。利用者は地物を選んで属性を読めます。左下の
操作のカードにある 4 つのスイッチで、編集を止める 4 つの方法を別々に
切り替え、それぞれが何を止めるかを見せます。

```example
read-only-viewer
```

街区か停留所をクリックしてください。右のパネルに名前、計測値、属性が
文字で出ます。描画が読み取り専用の間は、そこで何も変えられず、削除と
ロックのボタンは押せません。隠すボタンは残ります。隠すのはこのページの
中だけのことで、何も書き込まないからです。左の凡例のタブには、街区の
用途ごとの色が出ます。

このページは読み取り専用で開き、ほかの 3 つは切れています。スイッチは
地図の左下の操作のカードにあり、それぞれにキーがあります。スイッチを
押しても、キーを押しても、入と切が変わります。`?` でキーの一覧が出ます。
パネルの欄に入力している間は、キーは働きません。どのスイッチも、切り
替えた後の状態をブラウザーのコンソールに出します。レイヤーのパネルの
ロックと目で変えた状態も、スイッチに出ます。

| 操作 | キー | すること |
| --- | --- | --- |
| 読み取り専用 | `R` | 利用者とコードからのすべての書き込みを止めます |
| 操作の錠 | `K` | 利用者の操作だけを止めます |
| Blocks をロック | `B` | Blocks の地物へのすべての変更を止めます |
| Blocks を隠す | `H` | このページで街区を隠します。何も保存しません |

読み取り専用の間も、道具のバーの道具は始まりますが、描いたものは残り
ません。レイヤーのロックも書き込みなので、「Blocks をロック」も断られ、
スイッチは切のままです。読み取り専用を切って書き込めるようにしてから、
操作の錠を入れてください。道具は始まらなくなり、何も動かせなくなります。
それでもクリックで選べますし、コードは書き込めます。操作の錠を切って
「Blocks をロック」を入れると、街区は選べても動かせず、変えられなく
なります。停留所は動かせます。「Blocks を隠す」は、読み取り専用の間も、
このページで街区を隠します。文書の中のレイヤーは見えるままなので、次に
開いたときもほかの人も、街区を見られます。

## コード

先に、描画を 2 つのレイヤーに読み込みます (3)。まだ書き込めるうちに
読み込むためです。次に `setReadOnly(true)` で、利用者からもコードからも
書き込みをすべて断ります (4)。標準の UI は、オプションで見るためのページに
合わせます (2)。レイヤーのパネルでは追加も並べ替えもさせず、
インスペクターは属性のタブだけにして演算を出しません。描画が読み取り
専用の間は、インスペクターが出す欄はすべて変えられなくなります。4 つの
切り替え (5) は、`setReadOnly`、`setInteractionLocked`、`locked` を渡す
`layers.update`、`draw.hidden` です。`layers.update` は断られると `null`
を返します。`draw.hidden` はレイヤー、グループ、地物の ID を受け取ります。
これらは標準の UI の操作で (6)、`ui.actions.add` で足します。それぞれが
キーと `checked` を持ちます。カードは `checked` を、押すたびと
`ui.actions.refresh()` のたびに読み直します。ページはコアのイベントで
`ui.actions.refresh()` を呼びます。
