# Playground

ライブラリーのすべての機能を 1 つのページに載せています。すべての部品を
出した標準の UI、道具と節を足したプラグインと独自の地物の型、地形、
地球儀、データセット、読み取り専用と操作の錠、ブラウザーへの保存、
20 万の地物です。

```example
playground
```

ページは東京駅の東の描画を開きます。この描画は、地図のスタイルの
レイヤーにはできず、このライブラリーの 1 つのレイヤーにはできることを
見せます。地物ごとに自分の見た目を持てることです。Drawing のレイヤーには、
塗りと輪郭の色が違う 3 つの面があり、輪郭は実線、破線、点線で、太さは
1、3、6 px です。ほかに太さ 1、4、10 px の 3 本の線、輪郭のある 4 つの形の
点 (グループにまとめています)、半径をメートルで持つ円、フリーハンドの線、
画像があります。Land use のレイヤーはカテゴリーのスタイル規則で区画を
塗り分け、凡例のタブにその規則が出ます。

ページのアドレスで、開くものを選べます。

| アドレス | 開くもの |
| --- | --- |
| (なし) | 上の描画 |
| `?plain` | レイヤーが 1 つの空の描画 |
| `?showcase=<scene>` | README の画像の別の場面 |
| `?locale=ja` | 日本語の標準の UI (上のどれとも組み合わせられます) |

場面は `tilted`、`terrain`、`globe`、`large-data` です。

下の道具で、点、線、面、円、フリーハンド、画像を描きます (画像の道具は
ファイルを尋ねます)。星はプラグインのモードで点を置き (`S`)、ルートの
道具は独自の型の地物を置きます (`R`)。どちらも右のパネルに自分の節を
持ちます。右下の地球儀のボタンで投影を切り替えます。地図にファイルを
落とすと、その場所に読み込みます。

道具でない切り替えは Shift を押しながらのキーです。ページを開いたときに、
ブラウザーのコンソールにも一覧が出ます。

| キー | 切り替え |
| --- | --- |
| Shift+T | 地形を出す、消す |
| Shift+D | 1 万のセルのデータセットを出す、消す |
| Shift+R | 読み取り専用にする、戻す |
| Shift+K | 操作の錠をかける、外す |
| Shift+S | 描画をこのブラウザーに保存する (localStorage) |
| Shift+O | このブラウザーに保存した描画を開く |
| Shift+B | 20 万の点を地物として読み込む、取り除く |

20 万の点のレイヤーは、レイヤーのパネルに地物を並べず、その数だけを
出します。1,000 より多くの地物を持つレイヤーはどれもそうです。

## コード

ページは `playground/` にあり、`npm run dev:playground` で単独で動きます
(ポート 3300)。プラグインは [Plugins](plugins.ja.md) の例から、型は
[Custom feature types](custom-feature-types.ja.md) の例から取り、その道具と
節を `ui.tools.add` と `ui.inspector.sections.add` で足します。
