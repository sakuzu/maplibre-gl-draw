# Playground

ライブラリーのすべての機能を 1 つのページに載せています。すべての部品を
出した標準の UI、道具と節を足したプラグインと独自の地物の型、地形、
地球儀、データセット、読み取り専用と操作の錠、ブラウザーへの保存、
20 万の地物です。

```example
playground
```

ページは東京駅の東の描画を開きます。描画には 5 つのレイヤーがあります。
奥から順に次のとおりです。

- Land use は 9 つの区画をカテゴリーのスタイル規則で塗り分けます
- Draft (50%) は不透明度を半分にして描きます
- Zones には穴のある面 (頂点のハンドルが見えるように選んでいます) と
  マルチポリゴンがあります。ほかに 3 つのグループがあり、半径をメートルで
  持つ重なった 3 つの円、塗りの濃いものから薄いものまでの 5 つの四角、
  輪郭が実線、破線、点線で太さが 1、3、6 px の 3 つの面をまとめています
- Routes には太さ 1.5 から 12 px までの 5 本の線と、破線と点線の小道の
  グループがあります
- Notes には画像、それを囲むフリーハンドの線、4 つの形の点のグループが
  あります

レイヤーの下には、細かい六角形のセルのデータセットがあり、段階区分の
規則で塗り分けています。凡例のタブには、Land use とこのデータセットの
規則が出ます。

ページのアドレスで、開くものを選べます。

| アドレス | 開くもの |
| --- | --- |
| (なし) | 上の描画 |
| `?plain` | レイヤーが 1 つの空の描画 |
| `?showcase=<scene>` | README の画像の別の場面 |
| `?locale=ja` | 日本語の標準の UI (上のどれとも組み合わせられます) |

場面は `tilted`、`terrain`、`globe`、`large-data` です。

下の道具で、点、線、面、円、フリーハンド、画像を描きます (画像の道具は
ファイルを尋ねます)。星はプラグインのモードで点を置き (`S`)、ルートの
道具は独自の型の地物を置きます (`R`)。どちらも右のパネルに自分の節を
持ちます。右下の地球儀のボタンで投影を切り替えます。地図にファイルを
落とすと、その場所に読み込みます。

道具でない切り替えは、地図の左下の操作のカードにあります。それぞれに
Shift を押しながらのキーがあり、`?` で一覧が出ます。スイッチは、ほかの
部品やコードが状態を変えたときも、今の状態を出します。

| 操作 | キー | すること |
| --- | --- | --- |
| 地形 | Shift+T | 地形を出します。また消します |
| 1 万のセル | Shift+D | 1 万のセルのデータセットを出します。また消します |
| 読み取り専用 | Shift+R | 読み取り専用にします。また戻します |
| 操作の錠 | Shift+K | 操作の錠をかけます。また外します |
| 20 万の点 | Shift+B | 20 万の点を地物として読み込みます。また取り除きます |
| 保存 | Shift+S | 描画をこのブラウザーに保存します (localStorage) |
| 開く | Shift+O | このブラウザーに保存した描画を開きます |

地図だけを見せる場面 (`tilted`、`terrain`、`globe`、`large-data`) には
UI がないので、切り替えもありません。

20 万の点のレイヤーは、レイヤーのパネルに地物を並べず、その数だけを
出します。1,000 より多くの地物を持つレイヤーはどれもそうです。

## コード

ページは `playground/` にあり、`npm run dev:playground` で単独で動きます
(ポート 3300)。プラグインは [Plugins](plugins.ja.md) の例から、型は
[Custom feature types](custom-feature-types.ja.md) の例から取り、その道具と
節を `ui.tools.add` と `ui.inspector.sections.add` で足します。切り替え
(`switches.ts`) は `ui.actions.add` で足します。ページは、切り替えが
出す状態を変えるコアと地図のイベントで、`ui.actions.refresh()` を
呼びます。
